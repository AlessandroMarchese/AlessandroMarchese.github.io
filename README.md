## Research & Projects  
- [**Estimating Continuous Treatment Effects with Recourse Data <span style="color: rgb(138, 43, 226);">@NeurIPS 2026</span>**](https://openreview.net/pdf?id=b8XmjZmsN0): A recourse-based framework for continuous treatment effect estimation that leverages counterfactual explanations as causal supervision, using Lynden–Bell reweighting to correct selection bias and estimate dose-response curves even when standard treatment overlap fails.

- [**CLEXNET <span style="color: rgb(138, 43, 226);">@NeurIPS 2025</span>**](https://openreview.net/pdf?id=b8XmjZmsN0): A causal-explanation-guided model for organ-offer acceptance that learns policy-invariant representations using refusal-reason signals to improve generalization and predictive reliability.

- [**DynamITE <span style="color: rgb(0,150,0);">@ML4H 2024</span>**](https://raw.githubusercontent.com/mlresearch/v259/main/assets/marchese25a/marchese25a.pdf): A novel methodology for time‐sensitive organ allocation that explicitly models acceptance behaviours and cold ischemic times across sequential offers.
